# TypeScript & OOP Assignment

This repository contains my solutions for the **Problem Solving with TypeScript & OOP** assignment. It covers basic types, optional parameters, readonly tuples, interfaces, type narrowing, generics, Promises and object-oriented programming.

## Contents

- [`solutions.ts`](./solutions.ts): solutions to all 8 problem-solving tasks
- Blog posts:
  - [Type Alias vs Interface in TypeScript](./type-vs-interface.md)
  - [Type Narrowing in TypeScript](./type-narrowing.md)

## Problems Solved

1. `multiplyValue`: optional parameter with a default multiplier
2. `processInput`: union types and `typeof` narrowing
3. `formatCoordinate`: readonly tuple
4. `concatenateArrays`: generics with rest parameters
5. `Course` and `getPopularCourses`: interface and filtering
6. `pluckValues`: generics with the `keyof` constraint
7. `Employee` and `Manager`: classes, inheritance and access modifiers
8. `validateAgeAsync`: Promise with `setTimeout` and error handling
